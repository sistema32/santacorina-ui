JS / Utilidades

Lo que no es CSS: formato de moneda/fecha, portapapeles, toasts y el resto de funciones JS que exporta el paquete.

Utilidades JS

Primera vez que el paquete incluye JS, no solo CSS. Dos modos de consumo:

Sin bundler (plantillas Jinja de sgp/web)

<script src="node_modules/@sistema32/santacorina-ui/dist/js.global.js"></script>
<!-- Santacorina.formato.conSigno(-6014510) -- "-$6.014.510" -->
<!-- .lateral-toggle, .tabs, data-rango-fechas y data-calendario ya funcionan solos -->

Con bundler (Vue de sgp/frontend)

import { formato, mostrarToast } from "@sistema32/santacorina-ui/js"
