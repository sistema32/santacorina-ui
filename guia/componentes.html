La cifra es el gráfico: manda ella, sin recuadro que la sostenga. El color del estado es la marca corta de arriba, no un marco. .delta es opcional y compara contra un período con nombre — es el único texto del paquete que lleva color de dato, porque ahí el color es la dirección.

La etiqueta tiene que decir el estado. data-tono refuerza, nunca reemplaza: si el único que sabe que algo anda mal es el color, quien no distingue rojo de verde no se entera. Por eso la etiqueta dice «Establecimiento sobregirado» y no «Alertas». Los dígitos van proporcionales a propósito — tabular-nums le da a cada uno el ancho de un cero y a 34px un «121» se ve flojo; lo tabular es para columnas que deben alinearse, y ahí sigue estando (td.peso).

Confirmación reutilizable

confirmar(opciones) (0.26.0) arma un .modal al vuelo reusando abrirModal/cerrarModal -- foco atrapado, Escape vía la pila de capas, todo gratis -- y devuelve Promise<boolean>. Foco inicial en Cancelar, salvo peligro: false.

Santacorina.confirmar({
  titulo: "Eliminar adjunto",
  mensaje: "Esta acción no se puede deshacer.",
  textoConfirmar: "Eliminar",
  peligro: true,
}).then((ok) => { if (ok) /* eliminar de verdad */ });

Selección de filas

De Carbon Design System (data table). iniciarSeleccionTabla conecta el checkbox de cabecera ([data-seleccionar-todo]) con el de cada fila ([data-seleccionar-fila]): marca/desmarca solo las filas visibles en esa tabla — el paquete no sabe cuántas hay en otras páginas del servidor, así que "seleccionar las N de todas las páginas" queda fuera de alcance. Dispara santacorina:seleccion-cambiar y muestra/oculta .barra-seleccion (calcada de .total-caja).
