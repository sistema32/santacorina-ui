El sistema de diseño de Santa Corina

@sistema32/santacorina-ui es un plugin de Tailwind CSS v4: tokens de marca + los componentes que Tailwind no trae de fábrica. Este CSS lo sirve directamente dist/ui.css — lo que ves es exactamente lo que recibe cualquier proyecto que instale el paquete.

Lo que esta página está usando ahora mismo

Ninguno de estos valores está escrito a mano: el navegador lee el :root de esta página, que sale de dist/ui.css tal como se publica. Cambiá el tema arriba a la izquierda y la tabla cambia con él.
