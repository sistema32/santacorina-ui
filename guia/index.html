SLEP Santa Corina

@sistema32/santacorina-ui

Plugin de Tailwind CSS v4: tokens de marca + los componentes que Tailwind no trae de fábrica. Este CSS lo sirve directamente dist/ui.css — lo que ves es exactamente lo que recibe cualquier proyecto que instale el paquete.

La guía está dividida en Layout, Formularios, Componentes y JS / Utilidades -- el nav de la izquierda ya te lleva a cualquiera de las 4 desde esta misma página.

Tokens

Color semántico: azul = informativo/en curso, verde = conforme, naranjo = alerta/pendiente, rojo = rechazado o sobregirado, gris = neutro.

navy#0c2d4a
azul#2a78d6
verde#1e8e5a
naranjo#d97a12
rojo#c8362f
gris#7a8794

Tipografía

Public Sans (licencia SIL Open Font) es la tipografía de marca por defecto — diseñada para el US Web Design System, pensada para texto denso en tablas y formularios de gobierno. El paquete no carga el <link> de Google Fonts por su cuenta (un plugin no debe imponer una petición de red); sin él, el navegador cae a system-ui, exactamente igual que antes de 0.9.0.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Public+Sans:wght@400;600;700&display=swap">

El valor vive en la variable --font-sans — mismo nombre que usa Tailwind para su propia utilidad font-sans, así que el override (sin @layer, igual mecanismo que los colores) también alcanza a esa utilidad y al <html> base, no solo a body.

:root { --font-sans: 'Inter', sans-serif; }

Íconos

100% CSS vía mask-image + background-color: currentColor — heredan el color de texto como cualquier letra. Reemplazan los glifos sueltos (✓/✔ inconsistente, ✕, →) repetidos a mano en decenas de plantillas de sgp. Cada clase es icono-<nombre> — hacé clic en cualquiera para copiar el HTML.

<span class="icono icono-check"></span>
